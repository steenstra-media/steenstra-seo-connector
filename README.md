# Steenstra SEO Connector

WordPress-plugin van [Steenstra Media](https://www.steenstramedia.nl/) voor beveiligd SEO-beheer van klantwebsites.

- Accepteert alleen digitaal ondertekende aanvragen (Ed25519) van Steenstra Media.
- Werkt met pagina's, ACF-velden, SEO-titels en -omschrijvingen (Yoast SEO en Rank Math), FAQ-schema en afbeeldingen.
- Past nooit thema-bestanden, menu's, plugins, gebruikers of instellingen aan.
- Elke wijziging wordt gelogd en is terug te draaien (Tools → Steenstra SEO).
- Updatet zichzelf vanuit deze repository; updates worden alleen geïnstalleerd als de handtekening en het controlegetal kloppen.

## Installatie
Download de nieuwste zip uit [`releases/`](releases/) en upload hem via Plugins → Plugin toevoegen → Plugin uploaden. Daarna updatet de plugin automatisch.
